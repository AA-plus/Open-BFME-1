The original bank declared a const clamp array and indexed it from the interior zero point. The canonical datum is the mutable array g_bfmeClampTable at VA 0x01356EE0, with its zero point 256 bytes later. This is recorded in the existing DIR32 and data ledgers and defined in BfmeLoopFilterHoriz.cpp. Every new candidate uses the existing writable symbol and an explicit 256-byte addend. The four final COFF relocations all name ?g_bfmeClampTable@@3PAEA and contain that addend. This corrects the declaration and address identity without adding a pin. The instruction mismatch prevents a final strict relocation acceptance claim.

## Remaining differences and reopening condition

Every fully resolved difference, including the overrun, is listed in build/rva009ae6a0-finish/best-resolved-difference-offsets.json. The diagnostic masked offsets are in best-difference-offsets.json. Full raw streams and instruction alignment are in best-retail-decode.log, best-compiled-decode.log and best-aligned-diff.log. The first differing byte is +0x59, an entry-guard displacement to the shifted epilogue. The independent SIB residues are in the byte loads at +0x18F and +0x1D9; they address the same bytes with exchanged base and index registers. The archived tap copy removes the earlier +0x1CD SIB residue. The first substantive scheduling divergence remains +0x38A, where the destination-stride reload is moved ahead of arithmetic. The final vertical LPF output also computes its dead running sum and last pixel in a different order starting at +0x411. These differences shift the fallback stores and later branch displacements.

At horizontal entry +0x530, retail loads x3 before x1 and x2, spills x3, and later retains x9. The reconstruction retains a different tap and emits different accumulator memory updates. Retail's third ABS merge at +0x59D differs in branch polarity and temporary use. The remaining horizontal region contains those spill and reload differences, a different placement of the explicit fallback block, and the final LPF accumulator schedule. These differences and the resulting ten-byte excess are unresolved compiler-shape evidence. The raw byte count is not an assertion that each differing byte is an independent algorithmic error. No assembly-only requirement has been proved.

Reopening needs native codec source or a distinct experiment grounded in these exact evaluation and control-flow differences. Repeating the closed tap permutations, storage hints or the unchanged generic flag and register searches has no new supporting evidence. A caller with a different argument setup, a target branch leaving the decoded extent, a constructor or ownership operation missed in the leaf decode, or a demonstrated pixel or variance mismatch would refute the retained ABI and behavior findings.
