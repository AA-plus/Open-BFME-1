## Refutation conditions

A different primary vtable or a receiver adjustment at the verified caller would refute the method ABI. A throwing operation or retained reference in the complete finder would refute the non-throwing declaration. An additional field in the actual StringBase copy helper would refute the string view. A different predecessor, cleanup receiver, delete form or resolved destructor in the compiled unwind map would refute the ownership recovery. Any ordinary scoped gate failure prevents a byte-verified landing even if the probe is exact.
