## Hypotheses and refutation conditions

The current constructor, initializer, mode setter, destructor and grid-update sources were read directly. Their declarations already existed in the preceding complete attempt. No newly landed row or pin resolves that attempt's local-placement blocker. The old live bank is an entry skeleton, whereas the immutable history contains the complete reconstruction used here. Both were measured against the full retail extent before selecting the complete reconstruction.

The new experiments asked whether the three-float grid value's construction and assignment, rather than implicit aggregate copying, determined the misplaced shader and vertex locals. Supporting evidence is the complete target's three reads from each accessor group and the uploaded fourth constant. Explicit copy construction, explicit assignment, separate values and value-returning accessors were independently compiled. A changed frame or byte distance no closer than the saved body refutes each spelling as a useful next shape. These experiments preserve the observed fields; they do not establish a named vendor type.

Two other independently decoded observations motivated trials. The highlight helper reads its first argument as a float, despite the existing pin's unsigned declaration, and the target converts integer edges at their uses. A float function-pointer view preserving the existing external symbol and integer edge locals were measured. Neither improved byte distance. A virtual stdcall device view tested implicit versus explicit receiver syntax without changing the observed slots. It also produced identical bytes and does not prove a canonical Direct3D interface version.

The flag-access trials tested the first divergence. Reading the global directly after writing the output flag moves that divergence but violates retail's read-before-write order if the arguments alias. That trial is rejected on semantic evidence. Duplicating output and device setup across the two flag branches preserves that order but measures worse. Prior EH switches, throw declarations, temporary shader constants, accessor visibility, declaration-order permutations and position-value trials were already recorded and were not repeated as new hypotheses.

## Remaining mismatch and checks

The first difference remains output-pointer and flag-load scheduling at +0x57 in the preferred complete body. Retail places the vertex array sixteen bytes above the candidate's array, with both shader vectors below it; the candidate places one shader vector above the array. Origin and width locals are also shifted, although the frame size and cleanup objects agree. Complete retail and candidate listings retain the surrounding x87 conversions and stores. These observations constrain a future value-lifetime experiment; they do not justify another unchanged register or x87 trial.

The scoped repository byte verifier applied to a temporary read-only candidate row fails. Its raw output is build/007d5020-retry/gate-candidate.log. The later string, constant, DIR32 and complete body gates are not claimed to pass. Existing byte globals at VAs 0x01307280 and 0x01307281 still have no recorded DIR32 names. No symbol, pin, class header or function ledger was changed. The inherited owner correction and independently supported global names remain prerequisites for a strict source claim, separate from the failed byte match.

The initial CSV check and pin consistency check pass; their outputs are build/007d5020-retry/check-csv-initial.log and pin-consistency.log. Final CSV output is build/007d5020-retry/check-csv-final.log. The exploratory declared-unmatched check refuses the scratch source because it owns no matched row. The class check exits successfully. The brief's file-path invocation of name_regression.py fails because this revision's CLI expects Git revisions, not file paths; no bank-to-source conversion was made. Their raw outputs are declared-unmatched.log, class-gate.log and name-regression.log in the same scratch folder. No full gate is required for this evidence-only change, and no landing certificate is asserted.

Reopening requires independently supported local value or lifetime structure that predicts a different arrangement, or new evidence for the flag-access expression that preserves alias behavior. Correcting an owner name alone cannot improve these bytes. The best existing body and every new trial are preserved; the recorded verdict reports the measured failure rather than replacing the better bank with an inferior experiment.
