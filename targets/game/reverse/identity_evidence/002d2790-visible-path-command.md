## Retry hypothesis and measured result

The initial hypothesis was that a native value temporary, absent from the bank, changed the local-slot rotation and the second transform's x87 scheduling. The saved bank reproduced at 565 bytes with 71 differing non-relocation bytes. Every difference is located against decoded instructions in build/exitdoor-002d2790/bank-offsets.log. The prefix differences are stack displacements for `loc` and `createPoint`; the middle run is the second transform's alias-copy storage and the placement of the three empty-vector stores; the final differences are `tmp` displacements. The first differing byte is at `+0x5F`, and the last is at `+0x17B`.

Value-returning transforms, explicit unaliased output copies, native Vector3 construction, native Coord3D construction and setters, empty-vector construction variants, parent-scope and grouped-coordinate lifetimes, header order, direct typed callee declarations, and alternate floating-point or processor options did not improve the bank. Their complete sources and unedited probe outputs are retained under build/exitdoor-002d2790/, with each measured result recorded in build/verdict.txt. The previous runs' declaration-order and EH levers were inspected before this retry.

The successful lever is visibility of the existing `AICommandInterface::aiFollowExitProductionPath` body. An inline definition retaining `__declspec(noinline)` reproduces the existing 220-byte callee while exposing its behavior to the compiler. The caller then reproduces all target bytes, including the local-slot rotation and interleaved vector stores, without changing either matrix expression. The definition is inline so it does not add a second strong provider of the already-owned helper. Making only the pathfinder wrapper visible did not change the bank's residue.

This claim has a direct refutation experiment: removing only the visible path-command definition while retaining its typed class, virtual declaration, parameter record and all final declarations restores the original 565-byte result with 71 differences. That experiment is preserved in build/exitdoor-002d2790/62-hide-follow.cpp and build/exitdoor-002d2790/62-hide-follow.log. The exact final-source probe is build/exitdoor-002d2790/final-source-probe.log. Thus the old stack-slot diagnosis identified the symptom, but callee visibility supplies a verified C++ lever.
