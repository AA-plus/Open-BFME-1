# 001CABE0 color-selection reconstruction

The retained reconstruction is a partial, not an exact recovery. The original bank reproduces 45 differing bytes over the complete 376-byte extent. The revised body differs at +0xD8, +0xE0, +0xFD and +0x100. The strict scoped comparison resolves every direct call and passes boundary, string and DIR32 checks. The remaining source blocker is register allocation. The tested base revision is d4e9ae266f98edc988e2acc83a0aa88d54eab7ad.

The original bank's boundary comment was incorrect. Complete retail decoding proves the half-open extent [0x001CABE0, 0x001CAD58), with the last RET at 0x001CAD57 and INT3 padding following it. All three return paths restore the saved registers and exception registration. No conditional branch leaves this extent. The body has no arguments on the stack, no hidden return storage and a full-width EAX result.

## Source corrections

Retail replaces the selected player with the contain query's result, including null. The original bank used an independent containedPlayer local and could retain the disguise player after a null contain result. The revised body preserves the containedPlayer name and assigns that result to colorPlayer before checking it. Inline contain, default-team, local-player and color accessors recover the register lifetimes and shared color-return block.

Canonical Color is signed Int, as declared in the reference GameClient/Color.h. The color getter and both color fields use that representation. The NameKeyGenerator declaration returns the canonical four-byte NameKeyType enum. The contain query takes and returns const Player pointers through a const receiver. The existing canonical Object header supplies the module-lookup declaration; no shared header is changed and no new pin is added. Unused linker aliases are removed.

The kindof read is the third word of the mask based at ThingTemplate+0xC8. The bank's m_kindOf name is retained on a three-word partial view, which exposes only the prefix needed by this body and does not claim the complete mask width. The +0x34 disguise index is signed, and +0x38 is a template pointer. The complete StealthUpdate constructor at 0x002ACB70 and serializer at 0x002AC200 independently witness both fields. The constructor initializes the index to -1 and the pointer to null. The serializer transfers the index as Int and uses the pointer for a template-name lookup.

Relationship value 2 is ALLIES. Common/GameCommon.h declares ENEMIES, NEUTRAL and ALLIES in that order, and the complete matched GarrisonContain query at 0x0021E340 compares its relationship result against 2 for its ALLIES path. The inherited RelationshipEnemy name is retained as an explicit compatibility enumerator for ALLIES. It must not be read as evidence that this value means enemies.

The newly introduced isDisguised inline was removed from the retained body. Its +0x38 view would emit an additional COMDAT under a name whose existing 0x002227D0 ledger copy reads +0x3C. That other copy is outside this assignment, and its name is not evidence for this target's field. Direct access to the independently witnessed +0x38 pointer retains the same near match without that conflicting helper.
