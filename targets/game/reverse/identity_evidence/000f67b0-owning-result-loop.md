# Reconstruction of 0x000F67B0

The target is the complete body beginning at RVA 0x000F67B0 and ending after the `ret 4` at +0x190. Its only return is reached by the initial null-object branch, exhausted iteration, a null returned entry, and both reference-count release paths. Every conditional branch remains inside this extent. The backward branches at +0xF6 and +0x112 return to +0xC3 and establish a repeated sum, which the preferred bank omitted. There is no outgoing tail jump in the main body. ## Compiler experiments and refutation

The preferred bank reproduced its reported differences. Restoring a loop without accessor layers grew the body and retained the wrong override branches. A visible recursive override resolver, separate nullable-template and scalar accessors, and ordinary float storage recovered the retail branch structure. Keeping next on the payload still omitted the pointer copy at +0xD1. Moving next onto the one-pointer owning result recovered that copy; changing only cursor declaration order was not the successful lever. The remaining frame-update register differences disappeared with the inline frame accessor, or with an explicit frame scalar local. Native-pair, byte-cursor, opaque-cursor, aggregate-copy, and several increment spellings did not resolve the payload-level helper's residue. Each trial source and unedited probe output is retained under build/f67b0-20261013, and the running measurements are in build/verdict.txt.

The bank's original names remain in declarations. The duplicated already-landed value definition and the unused barrier were removed. The source has canonical global declarations, uses the existing float-radius pin, and adds no pin. This is a source recovery of the assigned address, not a claim that its descriptive cache name is EA's original identity. A decoded caller that adjusts the receiver, gives the radius a different width, or proves a different cache offset would refute the ABI view. A different actual entry constructor/copy target, an additional field access in that complete helper, or a differing unwind cleanup target would refute the container or lifetime model.
