The Open BFME 2 donor Code/GameEngine/Source/Common/Rva006C0630Cluster.cpp at game.dat 0x006C0500 supplies a plain C++ body for the corresponding four-axis predicate. Its assembly blocks belong to the separate box-building function and are not ported. BFME 1 keeps the existing pinned BfmeBoxF0::rva00880AF0 spelling used by the matched caller; BfmeBoxF0 is an opaque stand-in, not a claim of an original native class name. The historical intersects spelling is not reintroduced.

The preceding matched contains body has two ret 8 paths followed by alignment and a four-entry switch table. Four INT3 bytes separate its complete 188-byte contribution from RVA 0x00880AF0. The target decodes completely through ret 4 at +0x125, ending at RVA 0x00880C18, followed by eight INT3 bytes. It has two return instructions, four x87 comparison blocks, no outgoing call, no tail jump, no indirect call and no exception frame. All conditional destinations remain inside the body. Its result is in AL, as the false and true paths explicitly write that register.

The complete 221-byte caller at 0x00880C30 writes two 32-byte stack records. At +0xD4 it calls the target directly, with the first record in ECX and the second record's address as the sole stack argument. It returns AL without widening or altering it. Both constructed records contain center floats at +0/+4, axis floats at +8/+0xC, perpendicular floats at +0x10/+0x14 and extents at +0x18/+0x1C. The construction uses x87 FSINCOS and FCHS for the four axis words; the target independently reads every one of the eight fields with floating-point instructions. These accesses establish the borrowed record layout and argument contract independently of donor names. No ownership, constructor, destructor or hidden result object is implied.

The original preferred bank reproduces 294 bytes with 74 differences, first at +0xD8. Its third comparison multiplies the held coefficient before loading the other coefficient, unlike retail. The donor's scalar four-argument inline dot helper and center-load conditional expressions reproduce the exact 296-byte body, including that held x87 value and every comparison branch. The port reuses the existing BFME 1 box layout and compiler flags in BfmeBoxContains.cpp, preserves the bank's descriptive arithmetic names, and introduces only static inline arithmetic helpers. The strict scoped gate verifies both this body and the unchanged 188-byte contains body in that source.
