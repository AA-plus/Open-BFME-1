# Variadic text formatter at 0x009B4390

The complete retail body is 610 bytes. Its preceding 0x009B4170 body returns at +0x21A, then five INT3 bytes lead to this body's start. Its sole plain return is at +0x261, followed by INT3 padding through the next body at 0x009B4600. All branches remain internal; it has no EH registration, constructor cleanup or container type.

The matched callers at 0x009AABB0 and 0x009AAC80 pass context, pixel offset and format as their first three dwords, followed by twelve and one formatting values respectively. Both complete callers clean their own stack. The target passes the address of the fourth incoming argument to `_vsnprintf` with the actual format and its 256-byte buffer. Its final return loads a 32-bit length into EAX. This supports `int __cdecl Rva009B4390CodecCall(void *, int, const char *, ...)`; the older fixed-argument void pin is an address stand-in and is not ABI evidence. The source keeps the bank's function name, raw context view, output, result, selected and other descriptive local names. The original donor name `_vp6_xprintf` is not claimed as a BFME 1 identity.

The complete target reads the signed row stride at context+0x1B8 and pixel-buffer pointer at context+0x25C. It initializes the buffer with one zero byte and 255 following zero bytes, formats the actual buffer and computes its strlen. The rectangle contains four 32-bit fields. The IAT directory and decoded argument setup independently establish each GDI import's stdcall parameter count. Cached indirect calls use SelectObject from VA 0x013590FC and GetPixel from VA 0x013590E0. These are import slots, not virtual dispatch. Return values used as handles and pixel colours are dwords.

The complete cleanup graph was inspected. The bitmap is selected twice before the font is selected. Drawing failure restores the old bitmap and deletes the bitmap before the common font and DC cleanup. Early bitmap creation failure goes directly to that common cleanup. The native code reads the font spill at +0x20 on early failures before it has necessarily been assigned; the donor retains the same uninitialized-local behavior and does not introduce an invented zero initialization. There are no C++ owning members or EH cleanup funclets to infer.

The new hypothesis was that the donor's aggregate buffer initialization and complete cleanup ladder restore the EBX output-offset and EBP zero lifetimes that earlier banks could not reproduce. A first mismatch at +0x1A or a changed failure-path cleanup would refute it. Retaining the bank's raw context view and names emits the same exact body and passes the snapshot name-regression check. The old bank emits 585 bytes with 388 differences outside relocation fields.
