## Independent identity and calling convention

The shipped FunctionLexicon record at RVA `0x00EA9464` contains key zero, name pointer VA `0x01087844` with the string `GadgetComboBoxSystem`, and callback pointer VA `0x0043A887`. That complete five-byte ILT thunk jumps to the assigned body. Adjacent twelve-byte records name `GadgetListBoxSystem` and `GadgetImageComboBoxSystem`. The record layout agrees with `Common/FunctionLexicon.h` and the system table in `Common/System/FunctionLexicon.cpp` in the Zero Hour reference. This establishes the name independently of the existing ledger pin and byte comparison.

The complete caller at RVA `0x00790450` is 27 bytes. It pushes three four-byte arguments followed by ECX, calls the same thunk, removes sixteen bytes, and returns with `ret 12`. The target therefore accepts a window pointer followed by three four-byte message words under the ordinary cdecl convention. It returns a four-byte handled result in EAX with plain `ret`. There is no hidden return argument or receiver adjustment. `GameEngine/Source/GameClient/GUI/Gadget/GadgetComboBox.cpp` in the Zero Hour reference supplies the corresponding public declaration and message semantics.
