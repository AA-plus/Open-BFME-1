# Fixed-ratio byte sampler at 0x009A9A20

The retained name is the bank's opaque `Rva009A9A20`. The donor's `_Scale1D_2t1_i` is not claimed as a BFME 1 identity. The complete matched `Rva009A9AD0Scale2D` selects this actual callback address when vertical scale is 2, ratio is 1 and the interlaced flag is zero. Its vertical callback calls push source, source pitch, source scale, source count, destination, destination pitch, ratio and output count as eight dwords, clean those arguments themselves and ignore a return value. The same canonical signed pitch and unsigned count declarations are retained for both reconstructed callbacks.

The 98-byte leaf starts after the previous return at 0x009A9A1A and five INT3 bytes. It ends with plain return at 0x009A9A81, then fourteen INT3 bytes lead to 0x009A9A90. All branches stay within the extent. It has no calls, outgoing tail jumps, receiver adjustment, hidden result storage, EH states, owning members or container payloads.

Following each saved-register push through the full decode confirms argument 5 as the destination base, argument 6 as its row step and argument 8 as the output count. Argument 7 is unused, as are source scale and source count. The target copies the first source byte, doubles the source pitch and computes subsequent bytes as `(3 * (top + bottom) + 10 * centre + 8) >> 4`. Source samples are zero-extended bytes; the final shift and loop comparison are unsigned. The independent complete caller and target refute the earlier stack-offset misreading that treated argument 7 as an output base.

The new hypothesis is that the donor's two indexed loop variables allow native pointer induction, restoring the EBP/ECX source cursors and EDX doubled pitch that the rolling-pointer bank could not reproduce. A different first register load or changed source/destination induction would refute it. Open BFME 2 Code/Libraries/Source/VP6/Scale1D.cpp at game.dat 0x001BA460 emits exactly 98 bytes with no relocations. The old bank emits 99 bytes with 76 differences, first at +1. The function shares the new sampler source with 0x009A9980 and uses no assembly or volatile storage. The snapshot name-regression check passes.

Raw complete target and caller decodes, checked callee inventories, old and donor probes and the two-function scoped gate are retained under `build/vp6-donor-ports/`. The primary probe is `9a20-donor-probe.log`. The final shared source passes its two-function scoped gate in `build/vp6-donor-ports/9a20-land.log`. An address-only compatibility pin retains the landed caller's reference to the withdrawn dump. Reopen this finding if a complete aligned callback call supplies a different argument order or a byte width inconsistent with the decoded loads and stores.
