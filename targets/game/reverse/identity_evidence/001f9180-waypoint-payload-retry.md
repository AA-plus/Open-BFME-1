The retry did not improve the saved reconstruction. ## New hypothesis and refutation

The previous record-type uncertainty can now be tested against the landed WayPoint parser and the actual overflow helper it calls. A native STLport 4.6 vector view with a two-integer payload could change the selector/base schedule that the opaque pointer view misses. The supporting evidence is the complete parser, its table binding and both-field copy instructions, rather than allocation size or the helper's template pin. Refutation is a complete compiler experiment that does not produce fewer than the bank's three residual bytes at the retail extent. The native vector experiments are worse.

A separate visibility hypothesis follows the local-order lever in `docs/shape_levers.md`: an inline count accessor in the bone-query argument may alter scratch-register assignment across that call. It does correct the later selector/base register order, but hoists an earlier count load and changes the coordinate-array argument register. Refutation is the complete byte comparison, which reports 32 differences. Moving the accessor definition outside the class keeps that result; a reference-returning accessor restores the original three differences. These experiments do not justify replacing the existing bank.

The previously established native coordinate lifetime remains supported by the current header, exported helpers and unwind action. This retry adds independent evidence for the record's second field and container layout. It does not resolve the selector/base register residue or the class-key Pathfinder declaration.

## Remaining blockers and checks

The remaining byte differences are the record selector/base displacement bytes at `+0xB8` and `+0xBE`, and the SIB byte at `+0xC4`. Retail loads selector `+0xC8` into ECX, base `+0xA8` into EAX, then forms `[eax+ecx*8]`; the bank assigns those loads to the opposite registers. Reopening needs an independently supported visibility or expression hypothesis that preserves the earlier argument setup while explaining these destinations. The newly proved second field and native vector view alone do not do that.
