## Compiler hypothesis and measurements

The unchanged bank emits 186 bytes with 77 overlapping non-relocation differences and four excess bytes. It places the returned string at ESP +0x10 and the byte argument at ESP +0x14. Retail places them at +0x14 and +0x10, respectively. Retail also reuses the getter's EAX result for the dispatch argument; the named bank local adds a second LEA. This creates the four-byte shift through the remainder of the loop and epilogue.

The retry hypothesis was that temporary lifetime and argument evaluation order caused the stack layout, rather than an immutable register-allocation residue. It would be refuted if a complete canonical full-expression version with the retail evaluation order still retained those differences. The inline byte accessor preserves the getter-first evaluation order and refutes the old stack-slot diagnosis: the resulting canonical source emits all 182 bytes exactly outside relocation operands.
