## Finishing hypothesis and rejected shapes

The original bank reproduces 152 bytes against the 154-byte extent, with 22 differing bytes outside relocations and two absent bytes. Its only structural change is MOV EAX,EDX at +0x7D where retail has LEA EAX,[ESP+0x20]; the shorter instruction shifts branch displacements and the tail. The bank also aliases an empty false-type tag onto its POD value instead of using a native pointer-vector temporary. Raw output is build/bcfa0/bank-probe.log.

Native pointer declarations alone emitted a 155-byte body with a separate empty-tag stack slot. Empty-tag constructors, destructors, factories, declaration qualifiers, split owner declarations and nested lifetime blocks did not recover the required homes. CSE suppression changed the prefix; no-alias switches retained the MOV and changed the finish update. Declaring the owner before the guard while still assigning each lookup result to the incoming parameter reproduced the two LEAs but moved ESI's save before the guard. These measured trials and their exact sources remain under build/bcfa0/, and build/verdict.txt records each result.

The successful source initializes the vector owner before the null guard, uses the real ErrorCode throw, and declares the lookup pointer locally in the loop. This lets the compiler place the thrown value, upgrade pointer and empty tag onto the dead argument home without moving the register saves. The for, while and do forms all independently reproduced the complete 154-byte shape; build/bcfa0/natural-for-before-guard.log, build/bcfa0/natural-while-before-guard.log and build/bcfa0/natural-do-before-guard.log retain those results. The final mutable-pointer source is exact in build/bcfa0/final-source-probe.log.

This recovery would be refuted by an outgoing branch or omitted return in either complete extent, another field read or written by the value-copy path, a different actual lookup or overflow target, an exception descriptor naming another type, or a strict gate failing to resolve the final source's call and data relocations. None occurred in the retained decoding and scoped gate. The original owner identity remains unknown and is explicitly address-derived.
