## Rejected experiments

The manifest contains 96 retained trial sources, of which 92 produced target measurements, with exact sources, hashes, and raw probe paths in build/411cd0-finish/trials-manifest.json. Tested hypotheses covered byte and bool declarations, enum categories, const declarations, class-body accessors, native module arrays and PlayerList accessors, base and vptr layouts, Bool aggregate storage, guard structure, loop carried values, ordered reads, argument normalization, abstract virtual declarations, typed dispatch adapters, and compiler switches from the matched Drawable caller. The register-family generator found no applicable adjacent definition swap in the original bank; its raw result is build/411cd0-finish/register-generator.log.

Two declaration-scope alternatives moved only uninitialized declarations, preserving every actual load and call. Both retained the residue. The finite shape_search receipt is build/411cd0-finish/declaration-scope-search.json, with raw probes in build/411cd0-finish/declaration-scope-0.log through declaration-scope-2.log. This distinguished declaration placement from the historical experiment that moved the module-list load before the guards.

The final helper-visibility experiment exposed the fully decoded Object and Team accessor chain using inline noinline copies. Both helper bodies reproduce their independently decoded extents, but the visible chain moves the player-list load past the Object call and makes the target one byte shorter. Ordering only that global load restores the original target residue without improving it. Raw source and probes are build/411cd0-finish/native-team-exact-shape.cpp, native-team-exact-shape.log, native-chain-player-load-order.cpp, native-chain-player-load-order.log, and their object-helper/team-helper logs. The earlier ternary Team copy was rejected because its helper was two bytes longer; it remains retained for reproducibility.

## Checks and reopening

The diagnostic scoped bank gate fails on its two unpinned address-view callee names; the separate relocation-aligned probe also remains nonmatching. Its raw result is build/411cd0-finish/scoped-gate.log. Pin consistency passes in build/411cd0-finish/pin-consistency.log. The final ledger check is retained in build/411cd0-finish/check_csv-final.log. No source recovery is claimed and no full gate is required for these evidence-only changes.

The remaining cause is unresolved receiver allocation and save scheduling. A concrete source experiment producing fewer differing bytes while retaining the complete boundaries, physical call contracts, and established bank names would justify reopening. The byte residue alone does not establish an assembly requirement. The existing real argument-append name also needs independent identity resolution before any canonical-name landing.
