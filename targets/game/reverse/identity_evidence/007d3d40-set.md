## Identity and boundary

Slot 3 points through ILT RVA 0x0004435A to the independently matched `ScreenCrossFadeFilter::postRender` at RVA 0x007D38B0. Its decoded call at offset 0x5A loads slot 0x14, pushes the mode, passes the unadjusted receiver in ECX and tests the complete EAX return. The Zero Hour `GeneralsMD` W3DShaderManager implementation identifies this operation as the protected virtual `set(FilterModes)` method and supplies the same circle-mask state ladder. This evidence would be refuted by a different constructor-installed table, a different thunk destination or a caller using a different receiver or argument contract.

The complete target has two ordinary return paths, at offsets 0x701 and 0x716. Both end in `ret 4`; the latter instruction ends at offset 0x719. Every direct conditional branch remains within this extent, and there is no external tail jump. The positive path returns the full-width value 1 in EAX; the nonpositive-mode path returns zero. The receiver is unused, but the virtual caller establishes its thiscall contract. There is no hidden return storage or receiver adjustment. Reachable control-flow checks, including indirect switch tables in the state-name helpers, are retained in `build/crossfade-007d3d40/cfg.txt`.

## New hypothesis and measurements

The preferred bank declares `Get_DX8_Render_State_Value_Name` with `throw()`. Retail's unwind map contains cleanup states for both render-state snapshot strings, so this annotation contradicts the observed call-site lifetime. Removing it alone emits the complete 1,817-byte masked instruction shape. The generated exception-flag experiment does not change the original bank's bytes. This hypothesis would be refuted if the decoded unwind map lacked those two string cleanups or if the corrected declaration still emitted the old shape.

The bank also calls its preset global `ScreenOpaqueShader`, recorded at VA 0x012D6E08, while the decoded target reads VA 0x012D6E14. The latter address is the existing `_PresetAlphaShader` datum. The twin explicitly passes `ShaderClass::_PresetAlphaShader`. The source keeps the bank's identifier as a local macro over that canonical accessor, so it introduces no new global or pin. Changing the preset alone leaves the old non-exact instruction shape; the ordinary scoped gate must verify its relocation, because a masked probe cannot distinguish these two globals.

The final body includes the shared string, shader, material, texture and DX8Wrapper headers. Plain native string-constructor inlining emits 1,655 bytes with 759 non-relocation differences. A local `inline` override around the string header retains its canonical class and forces the constructor into each snapshot call site, restoring the exact instruction shape. The temporary override ends before other headers. No shared header changes are needed. All trial sources and unedited probe outputs remain under `build/crossfade-007d3d40/` and the generated search receipt under `build/shape_search/ccbcbd14db00473c84a60f060fbcc2d9/`.

## Types, calls and ownership

`Get_Preset` at RVA 0x009212C0 reads one 32-bit preset index, increments the material's dword count at offset 4 and returns its pointer in EAX with caller cleanup. The target's material retain/release sequence uses that same dword field and receiver-only virtual slot 0. The shared `VertexMaterialClass` and `RefCountClass` declarations reproduce it. `BoxSetTexture` at RVA 0x00905AC0 takes a stage and a reference to one texture pointer; it reads the pointer through that reference, conditionally retains its low-word count at offset 4, releases the previous stage pointer, stores the new pointer and updates the dirty mask. This proves pointer ownership independently of the bank's type names.

The complete release helper at RVA 0x009EB7A0 tests the low word of the field at offset 4, decrements that word, and conditionally tail-jumps to virtual slot 0x20 when flag 0x01000000 requests deletion. The ledger carries both TextureClass and TextureBaseClass spellings there. This conversion reuses the shared TextureBaseClass declaration and adds no identity claim at that helper address. The one-pointer texture-handle cleanup at RVA 0x0005CC00 loads its owned pointer, returns for null and otherwise tail-jumps to this release body. It has the same contract as the final local TextureHandle destructor.

The complete StringClass helpers at RVAs 0x009DB890 and 0x009DB7A0 independently establish one buffer pointer at receiver offset zero. Get_String reads a 32-bit length and the low byte of its temporary flag, then returns with `ret 8`. It initializes or replaces that pointer and writes the allocation header at buffer minus eight and the string length at buffer minus four. Free_String releases either the temporary-pool reservation or the heap allocation and restores the empty-string pointer. All return paths and actual field accesses are in the retained complete decodes. There is no STL container, key or mapped payload in this target.

The state-name helpers at RVAs 0x00906FE0 and 0x00907BE0 read a StringClass output reference followed by two dword state/value arguments. Their ordinary returns and Format tail paths retain cdecl caller cleanup. Their switch tables were read as data and every selected destination checked against decoded instruction boundaries. Apply_Render_State_Changes at RVA 0x00904890 is a receiver-free, argument-free static call; its complete decoded body reaches its common return after processing the dirty state.

The indirect device operations push an explicit device pointer after their dword arguments and use stdcall function-pointer declarations. SetRenderState uses vtable offset 0xE4 with state/value; cached texture-stage updates use offset 0x10C with stage/state/value; sampler updates use offset 0x114 with the same widths. ADDRESSU and ADDRESSV become sampler states 1 and 2; MIPFILTER becomes sampler state 7 with value zero. These slot and argument contracts are witnessed in the complete target. The local Device and DeviceVtable names are inherited from the bank and claim no new runtime owner identity.
