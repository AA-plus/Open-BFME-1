## Rejected experiments and remaining blocker

The named local sentinel and the temporary expression produce the same improved shape when the count update is shared and assignment is visible. Making the forward copy, backward copy or growth body visible does not improve it. First-then-last snapshots worsen the result to 317 bytes with 239 differences. Reversing capacity and count declarations does not improve it. Reusing the result parameter for the recursive iterator gives 319 bytes with 135 differences. Iterator wrappers, iterator value copies, typed const-reference iterator parameters and typed const-reference pointer parameters give no improvement. An inline copy adapter gives 319 bytes with 135 differences. A structured nonempty guard repeats the preferred result. Sharing a single empty lifetime through a label gives 307 bytes with 242 differences and is rejected because retail has two states. All trials remain separate source files with raw logs.

The finite non-EH generator search retains its raw `result.json` under `build/shape_search/3a534a19dcac4c99bed3ffde9a2a6f64/`. Its capacity-array alternative gives 319 bytes with 142 differences; pointer alias and commuted addition alternatives repeat the preferred result. The EH generator search on the new visible-assignment context is retained under `build/shape_search/5b38e5c118fc40bf9762435342c33868/`. It finds no improvement, and two generated choices are syntax errors because the generator places throw() after a typedef. These failed generated sources and raw diagnostics are preserved. They do not constitute ABI evidence.

The remaining blocker is codegen-order at the initial source-iterator loads and saved-register allocation, followed by capacity and recursive-iterator storage. Reopening requires independently supported native iterator or local-lifetime context that changes that first divergence, or a verified donor with the same complete argument-load sequence. Repeating the exhausted declaration-order, visible-helper or iterator-wrapper shapes is not justified. Boundary, ownership and stack ABI are established; the original owner identity remains opaque by design.
